# 🚀 90 Days Coding Challenge

Welcome to my **90 Days Coding Challenge** repository! This space is dedicated to my commitment to **consistent problem-solving**, sharpening analytical thinking, and mastering **Data Structures and Algorithms (DSA)** through daily practice.

---

## 🎯 Core Focus & Objectives

* **Unwavering Consistency:** Showing up every single day for 90 days to build a strong, disciplined problem-solving habit.
* **Deep Algorithmic Thinking:** Breaking down complex problems, recognizing underlying patterns, and building strong intuition rather than memorizing solutions.
* **Time & Space Optimization:** Iterating from brute-force approaches to the most optimal solutions with thorough complexity analysis.
* **Clean & Modular Code:** Writing readable, maintainable, and well-documented code following best programming practices.

---

## 🧠 DSA Concepts & Patterns Explored

Throughout this challenge, the focus is on building a solid foundation across core computer science fundamentals:

* **Arrays & Strings:** Two Pointers, Sliding Window, Prefix Sums, Matrix Manipulation
* **Hashing:** Hash Maps, Hash Sets, Frequency Counting
* **Bit Manipulation:** Bitwise Operators, Bitmasking
* **Linked Lists:** Fast & Slow Pointers, In-place Reversal, Cycle Detection
* **Stacks & Queues:** Monotonic Stack, Priority Queues, Deques
* **Searching & Sorting:** Binary Search (on Arrays & Answer Spaces), Divide and Conquer
* **Recursion & Backtracking:** Subsets, Permutations, Combinatorial Search
* **Trees & Tries:** Binary Trees, Binary Search Trees (BST), DFS & BFS Traversals, Prefix Trees
* **Graphs:** Connected Components, Shortest Path Algorithms, Topological Sort, Union-Find
* **Dynamic Programming & Greedy:** Memoization, Tabulation, State Transitions, Interval Scheduling

---

## 📈 My Problem-Solving Approach

For every problem tackled during this challenge, I follow a structured workflow:
1. **Understand & Visualize:** Analyze the problem constraints, edge cases, and sample inputs/outputs.
2. **Formulate a Plan:** Identify the core data structure or algorithmic pattern that fits best.
3. **Implement:** Write clean, bug-free code in **Python**.
4. **Analyze & Optimize:** Evaluate the Time ($O(T)$) and Space ($O(S)$) complexity and refine the approach for maximum efficiency.
